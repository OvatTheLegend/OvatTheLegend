##  Engineering Philosophy

- **Layered Architecture:** Strict separation of concerns (Controller ➔ Service ➔ Repository ➔ Entity/DTO).
- **Relational Integrity:** Clean database modeling with foreign keys, indexes, and immutable Flyway migrations.
- **Testing Pyramid:** Unit tests, DataJpa slice tests, and WebMvc slice tests for resilient software delivery.
- **Modern Standards:** Java 21 LTS records, RFC 7807 ProblemDetails error handling, and TypeScript strict mode.
